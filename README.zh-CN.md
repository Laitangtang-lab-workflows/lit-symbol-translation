# lit-symbol-translation

**文献里的公式与数值进自己的工作前：先与自家记号建立显式映射、四轴核对内涵、代入原始公式重算——把量纲与口径错误挡在推导、代码和手稿之外的纪律。**

> [!NOTE]
> 本仓**全部内容由 AI 维护**，人类定方向、做决策，详见 [AI 维护声明](#ai-维护声明)。英文说明见 [README.md](README.md)。

## 解决什么问题

记号是最能藏研究错误的地方：两篇文献写同一个字母未必是同一个量，未经映射直接搬用的符号会埋下"看起来理所当然"的量纲或口径 bug，还能顺利活过审阅。本 skill 把防线规则化，提炼自真实仿真与手稿工作：

- **显式映射两种合法形态**——符号对照表（文献符号 → 自家符号 → 量纲 → 备注）用于成批引用，首次使用处一句话说明用于零星引用；只在心里默念对应关系属禁止行为
- **四轴内涵核对**——物理量定义、参考系、量纲、归一化基准，四项全过才算同一个量
- **三类典型差异**——参考系不同（喷嘴速度与基底速度）、特征基准不同（挤出物速度与入口速度；We 用的哪个特征速度？）、同名异义
- **无法对应即人工审核**——绝不猜测套用；标记、写明不确定点、等裁定
- **数值重算纪律**——文献数值经原始公式或守恒关系重推导并注明一手来源；转抄数值（含自己旧文档里的）不经验算不可用

刻意做小：一个概念、一页规则、超额的错误预防价值。
